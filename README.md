# My DotFiles

My personal dotfiles with various configurations.

All the settings and dotfiles have been structured for the **stow** software. For the correct instalation you can copy the respectives folders for your correct places or use the instalation process bellow.

## Instalation

For the instalation copy the folder for your home directory (make sure the folder name is dotfiles). Give the `install.sh` file executable permissions (`chmod +x install.sh`) and run it with `install.sh -i`
